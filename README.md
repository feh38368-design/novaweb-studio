# NovaWeb Studio

A mobile-first agency portfolio starter built with Next.js, React, TypeScript, and Lucide icons.

## Before publishing

1. Replace the temporary business name if desired.
2. Replace `hello@novawebstudio.example` in `app/page.tsx` with an email address you control.
3. Review all service claims and pricing. Prices are estimates and should match what you can deliver.
4. The Northstar Goods and ClearDesk entries are explicitly marked as concept demos. Do not present them as client work.
5. Add real screenshots and project links only for work you have permission to show.
6. Review the hosting provider's current terms before using its free plan for commercial activity.

## Run locally

Install Node.js, then run:

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Upload this project to a new GitHub repository and import that repository into Vercel. Use the default Next.js settings. No environment variables are required for this static portfolio starter.

## Important

The contact button currently uses a placeholder email address. Replace it before sharing the site with potential clients. This starter does not process payments, collect enquiries in a database, or provide a working booking system.
